# Generation Ship Simulator – Context Doc

## Inspiration
- Aurora (Kim Stanley Robinson)
- Oregon Trail (event-driven survival)
- RimWorld (emergent narrative)

## Core Themes
- Closed ecological systems
- Long-term generational consequences
- Human/social instability
- System fragility

## Design Intent
Create a simulation where:
- No system is fully understood
- Small issues compound over time
- Players must negotiate under uncertainty

## Player Experience
- Tension over time
- Incomplete information
- Tradeoffs without clear solutions
- Emergent storytelling

## Multiplayer Vision
- Different roles see different truths
- Players must collaborate and compete
- Informal power structures matter

## AI Role
- Agents simulate missing players
- Provide personality + negotiation
- Interpret system state

## Tone
- Slow, thoughtful, systemic
- Not twitch-based
- Narrative emerges from systems

## Key Differentiator
“Drift” — the system evolves beyond player control over time.
